# 路线查询 · 可操作原型

采用已选择的「顶部出发地页签 + 地图 + 目的地耗时表」布局。

## 当前可以体验

- 添加、编辑、删除出发地和目的地；删除后可以撤销。
- 一次选择一个出发地，复用同一组目的地。切换时清空旧结果并重新生成示例结果。
- 搜索示例地点，或通过地图选点设置位置。
- 点击驾车、公交、骑行、步行耗时，联动显示对应示例路线。
- 地图拖动、缩放、重置；移动端布局和可横向滚动的结果表。
- 地图来源菜单用于预览切换流程；开源方案尚不支持公交。

## 真实地图接入状态

这是可操作的前端原型，尚未接入任何真实地点搜索、道路、路况或路线规划 API。
地图背景是生成的虚构示意图，时长来自明示的演示数据，坐标是示意图像素，不能转换为真实地理位置使用。
高德、百度、开源方案的菜单切换不代表已调用这些提供方的真实服务，也不会消耗地图 API 配额。
真实地图接入需要用户自己的 API 配置、对应平台授权和独立适配；公交服务还需要相应的数据支持。
本原型不包含账户、云端数据存储或费用相关功能。地点修改只存在当前页面，刷新恢复默认数据。

## 本地运行

要求 Node.js 20.19+ 或 22.12+。

    npm install
    npm run dev -- --host 0.0.0.0 --port 4173 --strictPort

## 构建

    npm run build
    npm run test:sites

构建输出在 dist/client。保留的 Worker 和构建脚本可用于后续 Sites 发布，发布后的访问地址由 Sites 提供。

## 主要文件

- src/App.jsx：出发地、目的地、搜索、弹窗、加载与撤销。
- src/MapView.jsx：Leaflet 示意地图和路线渲染。
- src/model.js：示例数据和演示路网。
- src/styles.css：桌面与移动端样式。
- public/assets/city-map.png：生成的示意底图。
- reference/selected-design.png：本次选择的视觉参考。
- design-qa.md：浏览器验证和视觉对照记录。
