# 路线查询

保留「顶部出发地页签 + 地图 + 目的地耗时表」布局，接入高德 JS API 2.0。

## 功能

- 搜索高德真实地点，显示地址用于区分同名位置；支持地图选点和可选显示名称。
- 添加、编辑、删除多个出发地与共享目的地；删除后可以撤销。
- 一次选中一个出发地，切换后重新查询到同一组目的地的四种出行方式。
- 驾车、公交地铁、骑行、步行预计时长；点击时长切换地图路线。
- 真实 GCJ-02 坐标和高德返回的道路路径；没有数据或请求失败时明确显示状态，不生成替代时长或直线。
- 排队发送请求、限制并发，切换后丢弃旧结果并取消尚未发出的旧任务。
- 地图缩放、显示全部地点、响应式布局与可滚动表格。

百度和开源方案尚未接入，菜单中禁用。地点只保存在当前页面，刷新清空。公交、骑行、步行的覆盖范围和距离限制由高德决定；耗时为查询当时的估计。

## 运行配置

通过托管平台的运行时机密配置设置下列名称，不在源码或构建参数中写入值：

- `AMAP_JS_KEY`：Web 端 JS API Key，浏览器加载高德 SDK 时会使用此公开标识。
- `AMAP_JS_SECURITY_CODE`：配套安全密钥，仅由 Worker 转发请求时附加，不返回给浏览器。

如设置了高德域名白名单，需要允许部署站点的实际域名。SDK 的 `serviceHost` 指向同源 `/_AMapService`；代理仅允许地点、逆地理编码、算路和地图样式的固定高德端点，不转发站点 Cookie 或身份凭据。

## 开发与验证

Node.js 20.19+ 或 22.12+。

    npm install
    npm run dev
    npm run build
    npm run test:sites
    npm run test:maps

本地 Vite 提供与 Worker 相同的地图 API 适配；缺少运行时配置会显示连接失败。不要把生产安全密钥写入前端、测试快照或示例文件。自动测试覆盖固定上游代理、配置缺失、敏感值隔离、四种 SDK 算路结果、真实路径解析及过期请求取消。真实供应商连通性需要在部署环境另外检查。

## 主要文件

- `src/App.jsx`：地点管理、搜索、选点、表格及切换查询。
- `src/MapView.jsx`：高德地图、地点标记、多路线与视图控制。
- `src/amap.js`：SDK 加载、排队、真实地点和路线服务。
- `src/route-data.js`：坐标、POI、路线分段和错误转换。
- `worker/index.js`：运行时配置、服务器安全代理及静态资产/SPA 回退。
- `reference/selected-design.png`：已选视觉参考；其中示例文字已替换为真实接入状态。
- `design-qa.md`：检查结果及验证限制。

构建生成 `dist/client`、`dist/server/index.js` 和 `dist/.openai/hosting.json`，保持现有 Sites 项目与访问范围。
